# Theme samples

`sample-b-plus-minimal/` is an editable B+ theme package with `theme.json`, `components.json`, `theme.css`, and one local abstract background. It contains no JavaScript, people, brands, or third-party character material.

Generate its ZIP package with:

```powershell
node .\scripts\package-sample-themes.mjs
```

Import the directory or generated ZIP from the Skin Codex tray menu.
