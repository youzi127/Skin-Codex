# 主题验收清单

## 包与安全

- ZIP 能通过托盘“导入主题包”真实导入。
- 只有一套 `theme.json`，ID 合法且稳定。
- A/B/B+ 文件与声明一致。
- 无 JS、脚本、外链、`@import`、绝对路径、目录穿越和链接。
- 素材格式、单文件大小和总量符合当前校验器。
- 重复导入同 ID 为覆盖升级；删除主题后素材一并清理。

## 背景

- 背景图不包含伪造 UI、可读文案或水印。
- 整个窗口只绘制一次主背景。
- 无重复主体、人物、装饰或 Hero 残影。
- 侧栏、主区、标题栏和底部背景连续。
- 宽屏与窄窗口裁切保留主体，并给高密度信息留出可读区域。
- 切换首页/聊天不会突然换裁切或丢失背景。

## 路由与状态

- 首页、新聊天、已有长聊天、不同项目任务。
- B+ 首页：自有 Hero、行动卡和输入区可见且可操作；原生项目提示 `.skin-codex-native-home-prompt` 不与其重叠。切换不同项目名后复验，且查看计算样式，不以截图代替。
- 工具调用、文件变更卡、代码块、附件和多行输入。
- 菜单、弹窗、模型选择、权限选择和设置入口。
- 正常、hover、focus、active、disabled、loading/stop。
- 滚动顶部、中部、底部；输入框随内容变高。

## 功能

- 新建任务、切换任务、输入、发送、停止、附件、模型和权限可用。
- 侧栏滚动、会话滚动、复制代码、审查变更可用。
- 关键控件未被透明装饰层拦截，装饰层使用 `pointer-events: none`。
- 恢复官方外观后无主题节点、稳定类或样式残留。

## 视觉证据

- 至少保存一个宽屏和一个窄窗口截图。
- 检查文字不重叠、不溢出、不被背景吞没；对有插画背景的主题，分别检查浅色、深色与高纹理区域，且正文、代码块、工具卡和输入区都可辨识。
- 若使用内容级纱雾，确认它只跟随 `.skin-codex-message-content`，无边框、无固定圆角、不拦截操作，且在深色背景不会显成突兀白块。
- 不因沿用旧主题而出现固定黑框或深色粗描边；逐项确认边框颜色、粗细与阴影符合当前主题，而不是历史组件设定。
- 检查差异卡、工具卡和文件变更卡：默认无黑色/深色外框；若确需边界，必须是当前主题定义的低对比信息分组，而不是整块内容的默认描边。
- 若主题包含组件改造或微交互：记录主操作、次操作、选择器与卡片的 `default`、`hover`、`focus-visible`、`pressed`、`selected`、`disabled` 状态；确认动效服务于状态变化、无布局抖动，并在 `prefers-reduced-motion` 下停用非必要动效。
- 检查侧栏交界、标题栏、输入框四周和窗口底部像素。
- 对背景、输入框、底部遮罩和异常区域记录计算样式。
- `elementsFromPoint()` 证明异常区域没有额外不透明绘制层。

## 回归

- 运行 renderer/导入器相关测试和仓库完整测试套件。
- `git diff --check` 无新增格式错误。
- 从最终 ZIP 再导入一次。
- 切换到另一 A、B、B+ 主题，再切回当前主题。
- 不重启 Codex 的热切换通过；若必须重启，记录真实原因而不是把重启当修复。

## 交付说明

只报告已验证事实：主题等级、包含文件、测试结果、实机检查范围、已知兼容限制和最终 ZIP 路径。不要把概念效果图描述成已经实现的真实功能。
